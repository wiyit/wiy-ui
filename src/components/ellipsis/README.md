# Ellipsis 文本省略组件

## 简介

Ellipsis 组件是 wiy-ui 组件库中用于文本省略显示的基础组件，支持单行省略和多行省略，超出部分显示省略号。

## 用法

### 基础用法（单行省略）

```html
<wiy-ellipsis>
    这是一段很长的文本内容，当超出容器宽度时会自动显示省略号。
</wiy-ellipsis>
```

### 多行省略

```html
<!-- 2 行省略 -->
<wiy-ellipsis lines="2">
    这是一段很长的文本内容，当超过两行时会自动显示省略号。
    第二行内容...
    第三行内容...
</wiy-ellipsis>

<!-- 3 行省略 -->
<wiy-ellipsis lines="3">
    这是一段很长的文本内容，设置为三行省略显示。
    第二行内容...
    第三行内容...
    第四行内容...
</wiy-ellipsis>
```

### 配合宽度限制使用

```html
<div style="width: 200px;">
    <wiy-ellipsis>
        这段文本会在 200px 宽度处截断并显示省略号。
    </wiy-ellipsis>
</div>

<div style="width: 300px;">
    <wiy-ellipsis lines="2">
        这段文本会在 300px 宽度、两行后截断并显示省略号。
        更多内容...
    </wiy-ellipsis>
</div>
```

## 属性 attr

| 属性名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| lines | string/number | - | 显示的行数，不设置或设置为 1 时为单行省略 |

## 数据 data

本组件无内部响应式数据定义。

## 插槽 slot

| 插槽名 | 默认内容 | 说明 |
|--------|----------|------|
| default | 无 | 文本内容插槽，用于插入需要省略显示的文本 |

## 事件 event

本组件无事件定义。

## 实例函数 method

本组件未提供公开实例函数。

## 全局函数 global method

本组件未注册全局函数。

## 样式 style

Ellipsis 组件使用 CSS 实现文本省略，可通过 CSS 调整样式：

```css
wiy-ellipsis {
    /* 自定义宽度 */
    width: 200px;

    /* 自定义行高 */
    line-height: 1.6;

    /* 自定义字体大小 */
    font-size: 14px;

    /* 自定义颜色 */
    color: #333;
}
```

## 依赖

无依赖其他组件或第三方库。

## 注意事项

1. 组件默认行为是单行省略，不设置 lines 属性或 lines="1" 都为单行省略
2. lines 属性设置为大于 1 的数值时，使用 CSS -webkit-line-clamp 实现多行省略
3. 多行省略依赖浏览器对 -webkit-line-clamp 的支持（现代浏览器均支持）
4. 组件需要在有限宽度的容器中使用才能看到省略效果
5. 省略号的样式由浏览器默认样式决定，可通过 CSS 微调
6. 组件会继承父元素的字体样式（字体大小、行高、颜色等）
7. 多行省略模式下，组件的 display 属性会被设置为 -webkit-box
8. 单行省略模式下，文本不会换行，超出部分直接显示省略号
